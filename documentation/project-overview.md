# Project Overview

## Product Name

The current product name is `Atlas Wspomnień`.

## Goal

The goal of this project is to build a web application for a community-driven digital archive focused on preserving and sharing historical photographs tied to a specific area.

The system should support local residents, history enthusiasts, and administrators in collecting, describing, searching, and moderating photographic materials that document how places have changed over time.

## Main User Roles

- Administrator
- Viewer
- Creator

## Core Product Direction

The application will provide:

- a responsive web interface for browsing and searching archival materials,
- user accounts for contributors who upload and manage their own photographs,
- moderation and audit capabilities for administrators,
- a public REST API for searching materials,
- a private REST API for authenticated creators managing their own content.

## Non-Functional Priorities

The project will treat the following qualities as first-class requirements:

- accessibility aligned with WCAG 2.1 AA,
- responsive design,
- support for light, dark, and high-contrast display modes,
- maintainable architecture,
- clear documentation of technical decisions.
