# Accessibility Audit Checklist

## Purpose

This checklist is a working document for a systematic accessibility audit of the most important
user-facing screens and states in the project.

Suggested status values:

- `OK`
- `Problem`
- `N/D`

How to use the columns:

- `Klawiatura`: whether the flow works without a mouse
- `Fokus`: whether focus is visible and consistent
- `Formularze / Komunikaty`: labels, validation, status, loading, empty, disabled, and error clarity
- `Motywy`: light / dark / high-contrast behavior
- `Uwagi`: short note describing any issue
